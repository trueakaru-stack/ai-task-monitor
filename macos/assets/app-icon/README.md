# Application icon

The PNGs are unmodified exports of the user-supplied Figma frames for AI Task Monitor. The build script packages these exports into an `.icns` resource with the platform's `iconutil`.

Source: Figma file `NNKzKQ5N1LXdQaJONFZj3N`, page `0:1`; frames `5:522` (16 px), `5:480` (32 px), `5:466` (48 px), `5:452` (64 px), `2:422` (128 px), `2:384` (256 px), `2:371` (512 px), and `2:366` (1024 px).
