# About, Settings and update visual verification

The images were produced by the native macOS SwiftUI renderer in GitHub Actions run 41638506552, commit `dc8aee8`, at 560 × 700 pixels using synthetic tasks and a synthetic release. Both themes show the About page, Settings links and update dialog. The existing Settings screen and the supplied update-dialog image were used as references; colors, accent and continuous corners follow the application. Copy, action order and absence of an action divider were inspected. The run passed 58 tests and did not build an installer.

These previews do not verify hover, keyboard focus, VoiceOver, a real mail application, installation of an update, or a real Claude Code session.
