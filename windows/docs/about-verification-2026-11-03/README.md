# About and Settings visual verification

The images were rendered by the current WPF source at 590 × 760 pixels and 96 DPI with synthetic tasks. `dark.png` and `light.png` show the About page; `settings-dark.png` and `settings-light.png` show the new entries at the bottom of Settings. The existing Settings layout, typography and back navigation were used as the reference. The About text and links were inspected in both themes and small-window scrolling was tested.

These images do not verify actual mail-client availability, hover, keyboard focus, screen-reader behavior, other DPI scales, or a real Claude Code session.
