# Проверка недоступного источника

Дата: 2 ноября 2026. Локальный WPF-рендер исходников `windows/app/CodexProgress.ps1`; установщик не пересобирался. Источник Claude имитирован недоступным с помощью тестового пути-каталога; названия задач и планы демонстрационные.

Эталон геометрии — `screenshots/expanded-dark.png`, `screenshots/expanded-light.png`, `screenshots/compact-dark.png` и `screenshots/compact-light.png`. Согласованные изменения: сообщение над карточками в полном окне и под задачей в компактном; при пустом списке сообщение заменяет фразу об отсутствии активных задач. Неподтверждённая задача помечается текстом, а не считается активной.

Проверены снимки в этой папке: `full-*-1.png` и `compact-*-1.png` с работающей задачей, `full-*-0.png` и `compact-*-0.png` без задач, а также `full-*-unknown.png` и `compact-*-unknown.png` с неподтверждённой задачей. Для каждого сочетания просмотрены светлая и тёмная темы. Полное окно — 590 × 760 пикселей; компактное окно увеличивает высоту на имеющийся в приложении шаг, чтобы разместить дополнительную строку. Проверено отсутствие обрезки и сохранение прежней геометрии карточки. Результат: видимых расхождений сверх согласованных изменений нет.

Расчёт контрастности текста уведомления к фону: полное окно — 7,18:1 в тёмной теме и 6,69:1 в светлой; компактное — 5,65:1 и 4,58:1 соответственно. Это проверка цветовых значений, а не замена проверке средств доступности.

Автоматические тесты отдельно проверяют независимость источников, сохранение ранее замеченной задачи в неподтверждённом состоянии, восстановление и отличие отсутствующего нового журнала от исчезнувшего. Статусы средствами экранного доступа, клавиатура, прокрутка, и нативное приложение macOS в этой проверке не проверялись. Тестовая сессия Claude Code недоступна.
