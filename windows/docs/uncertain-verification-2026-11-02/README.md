# Проверка неподтверждённой задачи

Дата: 2 ноября 2026. Эталон — ранее сохранённые `screenshots/expanded-*.png` и `screenshots/compact-*.png`. Снимки `full-*.png` и `compact-*.png` созданы локальным WPF-рендером из текущего исходника при 96 DPI с демонстрационными данными.

В светлой и тёмной темах проверены полная карточка и компактный вид: статус отображается под заголовком, цвет точки компактной задачи не обозначает её как активную, план и процент его выполненных этапов остаются видимыми. Полное окно — 590 × 760 пикселей; высота компактного окна соответствует варианту с одной задачей. Видимого обрезания новой подписи нет; карточка использует прежнюю компоновку.

Расчёт контрастности подписи в полной карточке: 5,11:1 в тёмной теме и 4,95:1 в светлой. Значение дополняет визуальную проверку, но не заменяет проверку экранного чтения.

Тесты проверяют переход от активной задачи к неподтверждённой, сокрытие незамеченных старых записей и завершение. Реальный работающий чат Codex один раз сопоставлен с признаком занятой блокировки. Проверка не подтверждает поведение во всех версиях Codex или в длительных и аварийных сценариях. Клавиатурные и экранные средства доступности, прокрутка и macOS не проверялись.
