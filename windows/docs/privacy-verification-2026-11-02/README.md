# Проверка нейтрального названия Claude Code

Дата: 2 ноября 2026. Проверена локальная версия из `windows/app/CodexProgress.ps1` без сборки установщика. Данные на изображениях синтетические.

## Сравнение

- Эталон: ранее сохранённые `screenshots/expanded-dark.png`, `screenshots/expanded-light.png`, `screenshots/compact-dark.png` и `screenshots/compact-light.png` из этого же проекта.
- Результат: `full-dark.png`, `full-light.png`, `compact-dark.png`, `compact-light.png` в этой папке.
- Рендер: WPF, стандартный режим захвата приложения, 96 DPI. Полное окно — 590 × 760 пикселей; компактное — 390 × 198 пикселей, как у соответствующих эталонов.
- Проверено визуально: светлая и тёмная темы; карточка с планом и без плана; нейтральное название; обычный и компактный режим; пять видимых строк этапов; две задачи в компактной карусели; отсутствие лишнего процента у задачи без плана.
- Ожидаемые отличия от эталона: выбрана вкладка Claude Code, показаны две синтетические задачи вместо трёх; их названия нейтральны. Процент в примере с планом исправлен с ошибочных 46% на 33%: выполнено два из шести этапов.
- Результат сравнения: новая надпись помещается в карточке и компактном окне; непредусмотренных изменений геометрии в проверенных статичных состояниях не обнаружено.

## Ограничения

Это визуальная проверка синтетических данных, а не проверка реальной сессии Claude Code. Прокрутка, hover, клавиатурный фокус, сообщения о недоступности источника и ожидание подтверждения в рамках этого снимка не проверялись. Нативный рендер macOS и Swift-тесты на этом Windows-компьютере недоступны; визуальная приёмка macOS остаётся открытой.
