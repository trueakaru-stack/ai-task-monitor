# Application icon

The PNGs are unmodified exports of the user-supplied Figma frames for AI Task Monitor. The file `app-icon.ico` contains the 16, 32, 48, 64, 128, and 256 pixel exports as separate PNG-compressed ICO entries.

Source: Figma file `NNKzKQ5N1LXdQaJONFZj3N`, page `0:1`; frames `5:522`, `5:480`, `5:466`, `5:452`, `2:422`, and `2:384`, respectively.
