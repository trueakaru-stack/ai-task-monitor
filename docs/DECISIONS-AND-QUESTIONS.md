# Решения и открытые вопросы

## Индикатор активности задачи

- Источник: запрос пользователя об анимации точки, которая вытягивается и перемещается между краями.
- Решение пользователя: индикатор располагается слева от строки текущего действия под названием задачи.
- Затрагивает: расположение индикатора в развёрнутом и компактном окнах AI Task Monitor для Windows и macOS.
- Согласованная часть: индикатор должен визуально показывать работу задачи; прежнюю точку у названия следует заменить, а не дублировать.
- Уточнение пользователя: ширина области анимации — 16 px; её левый край совпадает с левым краем заголовка. Анимация индикатора работает независимо от системных эффектов, не меняя системные настройки.
- Форма по уточнению пользователя: круг превращается в прямоугольник с круглыми торцами, затем снова в круг на противоположном краю; движение повторяется в обратном направлении. Торцы не растягиваются в эллипсы.
- Дополнительное уточнение: высота индикатора уменьшена с 6 до 4 px, положение оптически выровнено с текстом текущего действия.
- После демонстрации последней локальной версии пользователь ответил: «Все ок».
