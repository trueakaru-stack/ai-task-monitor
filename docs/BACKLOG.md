# Бэклог AI Task Monitor

Здесь перечислены отложенные функции для Windows и macOS. Возвращение к каждому пункту и его реализация требуют отдельного согласования.

## Отложено

### Токены и оценка стоимости

Показывать доступные данные о расходе токенов по задаче и источнику. Связанную оценку стоимости рассматривать только при наличии надёжных данных о модели и тарифах; не выдавать её за фактические расходы по подписке. При отсутствии данных показывать, что они недоступны.

### Visual Diff

Опционально сравнивать макет с результатом реализации в сопоставимых условиях. Источники макета и рендера, масштабы и допустимые отклонения нужно согласовать отдельно. Функция не блокирует мониторинг задач.

## Ближайший порядок работы

1. Достоверность статусов и конфиденциальность.
2. Диагностические события: действия и ошибки, без дублирования существующего списка этапов плана.
3. Предупреждение о возможном цикле для Codex.
4. Проверка и расширение поддержки Claude Code при наличии тестовой сессии.

Журнал, предупреждение о возможном цикле и обработка неопределённого статуса реализованы в исходниках Windows и macOS. Claude Design остаётся условным: сначала нужен проверяемый источник событий и тестовая сессия.
